O que é a TrouxaNet?

A TrouxaNet é uma proposta de marca de serviços de internet, desenvolvida como projeto acadêmico. O trabalho reúne criação de identidade visual, organização de produtos e desenvolvimento de um site utilizando tecnologias web.

A proposta visual utiliza o contraste entre preto, branco e vermelho para transmitir personalidade e destacar as informações da marca. O amarelo aparece como cor complementar nos elementos de destaque.
